# Página Web Personal — Landing Page

Página web personal (landing page) desarrollada con **HTML y CSS**, como actividad
individual de creación de un sitio web personal. Es un sitio multipágina con presentación,
sección "sobre mí" y formulario de contacto.

> Proyecto de aprendizaje. Lo mantengo público como muestra de mis fundamentos de
> maquetación web y diseño de interfaces.

## Demo en vivo

🔗 **https://aitorser.github.io/Landing_Page/**

## Qué hace

Un sitio web personal con varias páginas:

- **Inicio** (`index.html`) — página principal de presentación.
- **Quién soy** (`quien_soy.html`) — sección con información personal.
- **Contacto** (`formulario_contacto.html`) — formulario de contacto.

## Qué demuestra

- Maquetación de un sitio **multipágina** con **HTML5**.
- Diseño y estilos con **CSS3** (organizados en la carpeta `CSS`).
- Navegación entre páginas y estructura de un sitio web personal.
- Publicación del sitio mediante **GitHub Pages**.

## Tecnologías

- HTML5
- CSS3
- GitHub Pages (despliegue)

## Cómo verlo

La forma más rápida es abrir la [demo en vivo](https://aitorser.github.io/Landing_Page/).

También puedes ejecutarlo en local:

```bash
git clone https://github.com/Aitorser/Landing_Page.git
cd Landing_Page
# Abre index.html en tu navegador
```
